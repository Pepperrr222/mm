# 数学建模项目目录

当前项目为 2026 年数学建模竞赛 C 题第 1 问。目录按“输入—模型—代码—结果—图表—历史资料”分层。

## 目录结构

| 目录 | 内容 |
|---|---|
| `01_题目与数据/` | 题目原文、建模分析、术语表和只读原始附件 |
| `02_团队协作/` | 三人分工、协作规范和技能使用说明 |
| `03_代码/` | 可复现的 Python 求解代码 |
| `04_结果/` | Excel 结果表、CSV 汇总、输入审计和复现清单 |
| `05_图表/` | 正式 SVG/PNG 图表；`图表目录.md` 说明各图用途；`previews/` 保存灰度预览 |
| `06_历史分析/` | 前期探索性分析、探针结果和历史图表 |
| `99_临时文件/` | Python 缓存等不参与提交的临时文件 |

## 复现

从项目根目录运行：

```powershell
python 03_代码/问题1_求解.py
```

代码会读取 `01_题目与数据/原始附件/`，并更新 `04_结果/` 与 `05_图表/`。原始附件不会被覆盖。
