# 分析材料说明

主报告位于上一级目录：`ABCD题目分析与选题建议.md`、同名HTML与Word文件。

`analyze.py`读取原始A/C/D工作簿，生成8组图、CSV统计与summary.json。B图为构造几何示意，不是模拟器数据。C单日LP采用输入时点为区间右端点、充放电效率各0.9、首末SOC均6000 kWh、允许弃电、不允许售电的假设。D整数规划只求不平移且忽略类别优先级时的最少撤销基准，不是第二问完整解。

运行方式及依赖详见主报告第8节。`render_report.py`生成离线HTML（内嵌图片）和Word（内嵌图片）。修改主报告后需重新运行该脚本。

图表目录：

| 编号 | 内容 | 性质 |
|---|---|---|
| 01 | A烘房环境和药材半径 | 原始附件可视化 |
| 02 | B三角形反例和交会角示意 | 构造图，非模拟器测试 |
| 03 | C四个指定日期负载和光伏 | 原始附件可视化 |
| 04 | C年度能量、净负载和价格 | 附件统计 |
| 05 | C光伏预报误差 | 全年描述性统计，非因果策略回测 |
| 06 | C第一问单日调度 | 明确假设下的LP初步试算 |
| 07 | D原计划时频占用与冲突矩阵 | 精确检测 |
| 08 | D类别冲突与装备度数 | 精确检测统计 |

CSV使用UTF-8 BOM编码，便于Excel直接打开。输入哈希保存在input_manifest.json，便于发现附件版本变化。本次没有修改problems目录内容。
