# 问题2图表契约

| 层级 | 文件名 | 核心论点 | 证据与图型 |
|---|---|---|---|
| 原始 | `raw_q2_monthly_energy` | 负荷与光伏存在显著月份变化 | 月度能量双折线 |
| 原始 | `raw_q2_netload_heatmap` | 净负荷同时具有日内与季节结构 | 日期×时段热力图 |
| 原始 | `raw_q2_forecast_error_distribution` | 因果日前预测误差可量化且存在离散性 | 箱线图叠加全部日观测点 |
| 过程 | `process_q2_solver_modes` | 全年求解由主模型及明确回退层级组成 | 月度堆叠计数图 |
| 过程 | `process_q2_storage_state` | 储能状态全年继承且始终满足容量边界 | 日初/日末状态折线与可行域 |
| 过程 | `process_q2_solver_time` | 各求解模式耗时分布不同，小样本不隐藏 | 对数散点图叠加中位数 |
| 结果 | `result_q2_monthly_cost` | 计划成本占主体，紧急购电造成附加费用 | 月度堆叠成本图 |
| 结果 | `result_q2_emergency_energy` | 紧急购电在月份间分布不均 | 月度购电量柱图 |
| 结果 | `result_q2_specified_dates` | 模板指定日期的逐时计划与应急购电可直接核查 | 四面板逐时曲线/面积图 |

统一输出为 7.2 英寸双栏宽度（指定日图高度 5.2 英寸），SVG 与 300 dpi PNG 并存；灰度预览置于 `previews/`。
